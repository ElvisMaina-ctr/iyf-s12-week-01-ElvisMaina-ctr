## Project Description
 This project is a responsive, multi-page personal portfolio website developed using HTML5 and CSS. It showcases my personal background, skills, education, projects, and contact information. The website follows semantic HTML principles and accessibility best practices to provide a user-friendly experience. It is deployed using GitHub Pages, making it accessible online.
 ## Project Features
  1. Home Page: Introduction, personal tagline, and welcome section.
  2. About Page: Personal background, skills, education, and experience.
  3. Projects Page: Showcases at least three projects with descriptions and images.
  4. Contact Page: Functional contact form with input validation and newsletter subscription.
  5. Responsive Design: Adapts to different screen sizes and devices.
  6. Navigation Menu: Consistent navigation across all pages with the current page highlighted.
  7. Accessibility: Semantic HTML, descriptive links, image alt text, and properly labeled form fields.
  8. Social Media Links: Connects visitors to my social profiles.
  9. GitHub Pages Deployment: Makes the portfolio publicly accessible online.
 ## Technologies used
